# Third-party notices

Riffscribe is built on other people's work. This file lists what ships to players, what runs only in
the evaluation harness, the licence of each, and the open questions about them. The licence of a
package is the one its own `package.json` or LICENSE file states on the date below; this is a record
for the maintainers, not legal advice.

Checked 2026-11-19 against the versions in `package-lock.json`. Items marked **Open** need a decision
(see "Open questions" at the end).

### chimera-vocal-synth

The harness borrows two things from `jamesondh/chimera-vocal-synth`
(https://github.com/jamesondh/chimera-vocal-synth), MIT licence, Copyright (c) 2026 Jameson Hodge:

- The **MusicXML note extractor** in `scripts/eval-cello/lib/musicxml-notes.mjs`, ported from that
  project's tools/musicxml-to-notes.ts with the lyric, syllable and wasm parts removed. The MIT
  notice stays at the top of the file, as the licence requires.
- The **scoring method** in `docs/eval-cello.md` and the stages' baseline-and-guard approach, adapted
  from that project's docs/csd-comparison.md: score each metric as a gap against a recorded earlier
  run, hold some data out, and fail on a regression. The idea is borrowed; no code is.

None of its synthesis engine, its AudioWorklet or its Rust build is part of Riffscribe, and none of
its audio data. (Its own evaluation set, CSD, is CC BY-NC-SA 4.0 and is not used here.)

## lamejs and the LGPL

`lamejs` is a JavaScript port of LAME, licensed LGPL-3.0. Riffscribe uses it unmodified through the
npm package and the bundler includes it in the studio's JavaScript. The LGPL lets a closed or
differently licensed program use the library, provided users can replace it with a modified version
and the library is acknowledged. A bundled web app makes the replacement requirement awkward to
state. LAME's own FAQ asks for acknowledgement and a link to its site (lame.sourceforge.net); this
file is that acknowledgement. Whether this satisfies the LGPL for the bundled build is a question for
whoever reviews the licences before Pro is sold; the straightforward alternatives are to load lamejs
as a separate script file the player can swap, or to drop MP3 export and keep wav.

## Open questions

1. **Demucs weights.** Keep, mirror, or move to a separator whose weights are licensed for commercial
   use (SCNet is the candidate; its model card quotes a maintainer's confirmation of the MIT licence,
   but both models were trained on MUSDB18-HQ, which is for educational use, so a changed licence on
   the weights does not by itself settle the training-data question). A lawyer, not the maintainers,
   should call this before Pro is sold.
2. **Basic Pitch training data.** The model was trained partly on non-commercial datasets. Unchanged
   by this release; listed so the question is not forgotten.
3. **lamejs and the LGPL**, as above.
4. **Cello samples.** The guide is a synthesised model, not recordings. If real samples are added
   later, the candidates are the University of Iowa solo cello (an informal "no restrictions"
   statement on its web page, no formal licence) and the CC0 VSCO-2 library (a cello section only, no
   solo cello). Written permission is needed for the first.
