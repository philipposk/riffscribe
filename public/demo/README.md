# Demo clip

`riffscribe-demo.mp3` is the song behind "Try the demo song" on the home page.

It is generated by `scripts/make-demo.mjs`. Nothing in it is a recording: a voice-like synthesised
line sings an eight-note melody twice (the second time five semitones higher) over a synthesised
pad, bass and snare. Run `node scripts/make-demo.mjs` to rebuild it; the output is deterministic.

It is released under CC0 (public domain dedication): use it for anything.
